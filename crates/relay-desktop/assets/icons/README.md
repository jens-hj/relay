# Relay icons

Relay's own line icons for navigation, window controls and page actions:
chevrons, board, director, worker, settings, add, profile sliders, window
minimize/maximize/close, commands, more, connections, reset and the phone
navigation button. They use `currentColor`, so they follow the text colour
around them, and the project license.

Harness glyphs, tool icons and every agent mark come from relay-ui
(`crates/relay-ui/assets/icons`).
