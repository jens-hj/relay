# Harness logos

The harness logos use the monochrome SVGs from theSVG, with their original
geometry and `currentColor` fill so they follow the UI's text color:

- `harness-codex.svg`: https://thesvg.org/icon/codex-openai
  (https://thesvg.org/icons/codex-openai/mono.svg).
- `harness-claude.svg`: https://thesvg.org/icon/claude-code
  (https://thesvg.org/icons/claude-code/mono.svg).

Both were retrieved on 2026-10-09. The upstream MIT license is included in
[theSVG-LICENSE.txt](theSVG-LICENSE.txt).

UI polish is tracked in [Relay issue #10](https://github.com/jens-hj/relay/issues/10).

The `tool-*.svg` icons are original Relay line drawings for terminal, file read, file change, search, web, agent, and fallback tool activity. They use `currentColor` and the project license. Tool presentation is tracked in [issue #21](https://github.com/jens-hj/relay/issues/21).
