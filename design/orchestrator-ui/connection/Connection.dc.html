Compound iconA square ring around a solid server square, a sibling of the context gauge. The ring fills with link quality: full under 80 ms, three quarters under 150, half under 300, a quarter above. Reconnecting keeps the solid centre inside a faint amber ring with two opposite gaps circling it. On connect one gap parks at the bottom opening and the other closes exactly where the measured speed fills the ring to. Offline fades the ring and slashes the centre in red.
TopologyThe panel draws the same thing large. Each node carries its revision; the HTTP lane has arrows both ways for request and response; the WebSocket lane is a thicker dashed line that flows while the socket is open. The protocol version sits on the link as a cut-corner tag.
Latency and endpointTwenty recent pings as bars, each coloured by how good it was: green under 80 ms, amber under 150, red above; the newest is full strength, older ones faded. The current value takes the same colour, with p95 beside it. A tick confirms the client and server revisions are compatible. The endpoint ends the panel in a ruled row with an embedded copy cell.
